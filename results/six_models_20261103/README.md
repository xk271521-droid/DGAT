# 六模型十数据集对比表

整理日期：2026-11-03

本版在原五模型表的每个目标数据块新增一行 `ProteinConvex + Strict RNA Calibration`。保留原始未校准 `ProteinConvex + Strict RNA` 行，便于同一目标内直接比较。

模型：原始 ProteinConvex、RNA 校准版 ProteinConvex、NicheTrans、DPAS-Graph、SPINE、DGAT。

统一输入为 10 个数据集、9384 个共同 RNA 基因和 31 个共同 ADT 蛋白。同组织 8 个方向、跨组织 4 个整组留出组/10 个目标。每个目标块 6 行；同组织明细 48 行，跨组织明细 60 行，总计 108 行。

六模型工作簿：`comparison/six_model_comparison_20261103.xlsx`。源五模型表保留在桌面及五模型结果目录，不覆盖。
