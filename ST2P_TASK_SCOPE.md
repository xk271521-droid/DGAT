# Retained model scope

The local benchmark contains seven frozen sections and four retained model tracks: V10-SharedNeighbor, original SCP-NET baseline, SCN-Pro-CognateAnchor, and SCN-Pro-ProteinConvex. MultiViewConsistency is historical only; its experiment code and run artifacts were removed on 2026-10-31. Shared data preparation and helper modules remain available only when required by the retained tracks.
