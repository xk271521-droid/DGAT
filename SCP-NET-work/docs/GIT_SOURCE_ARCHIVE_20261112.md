# 2026-11-12 私有 Git 源码归档记录

## 归档目的

按用户要求，把当前改进后的模型和本地保留的全部研究源码上传到用户自己的
`xk271521-droid/DGAT` 私有仓库。原有 `ST2P/.git` 的远程属于 `coderzhd/ST2P`，
本次使用独立的 `E:/DGAT/git-publication/` 发布副本，不改变旧仓库或作者仓库。

## 范围与文件真实性

- 原样包含当前初始粗糙度尺度门控、Strict RNA、Source Affine、ProteinConvex、
  CognateAnchor、共享 ST2P 模块、四种对照适配、保留的历史诊断代码和绘图源码。
- 运行目录中的 `script_snapshot.py` 是校准代码动态加载的依赖，因此一并保留。
- 同步保存参数、共同面板、源数据清单、紧凑指标、计划和错误/失败方案记录。
- 四个上游仓库依照已存固定版本清单完整复制作者公开跟踪文件，逐文件校验 SHA-256。
  对带 Git 对象的仓库从原始提交读取；不会把本地重新生成的字节码冒充作者原文件。
- 不改动研究源码字节、超参数、数据集、物理 checkpoint 或预测矩阵。
- 权重、原始/预处理矩阵、预测/注意力数组、环境目录、轮子包、冗余压缩包、
  临时脚本和聊天转储留在本地，不进入源码仓库。

## 验证与界限

`tools/export_source_snapshot.py` 保存可复用的导出过程；发布根目录的
`GIT_SOURCE_MANIFEST.json` 记录每个文件的相对路径、来源、字节数和 SHA-256。
导出检查覆盖：文件复制一致性、保留源码覆盖率、Python 静态语法、notebook JSON
结构和常见凭证格式。此操作不执行研究程序、不重新训练、不连接实验服务器。

这是源码归档，不代表换一台电脑无需数据和依赖就能直接得到相同结果。
原始启动脚本包含 `E:/DGAT`、Windows Python 和学校服务器路径；新环境需要配置路径。
Affine 校准脚本的默认 run root 指向旧基线，当前方法必须显式指定
`--run-root SCP-NET-work/runs/relative_roughness_gated_runs`，并使用新的输出目录。

历史文档仍保留当时的七切片/9764 基因协议；当前正式口径以根 README、
`REPRODUCIBILITY_AUDIT_20261104.md` 和当前实际源码为准。
所有 `oracle` 路径明确属于诊断分析，不能混写成正式无标签方法。
