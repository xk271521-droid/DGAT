# RNA 邻居一致性自适应门控：七折探索

该候选把固定的每蛋白校准强度改为 spot 级 RNA 邻居一致性门控。邻居越一致，校准权重越大；邻居冲突时保留更多原始预测。参数仍只使用每个外层折的源 validation spots 选择。

| 指标 | 原始 ProteinConvex | 自适应门控 | 固定严格 RNA 校准 |
|---|---:|---:|---:|
| 七折 PCC-Pro | 0.586593 | 0.590644 | 0.594800 |
| 七折 PCC-Spot | 0.629418 | 0.636568 | 0.644555 |
| 七折 RMSE-Global | 0.285059 | 0.278700 | 0.272659 |
| Breast PCC-Pro | 0.602035 | 0.605845 | 0.612301 |
| Breast PCC-Spot | 0.633267 | 0.635450 | 0.642322 |
| Breast RMSE-Global | 0.299574 | 0.295180 | 0.290963 |

自适应门控有效但没有超过固定蛋白特异 RNA 校准，因此当前主结果仍使用固定校准方案。
