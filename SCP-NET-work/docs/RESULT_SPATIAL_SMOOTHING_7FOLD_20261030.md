# 空间预测平滑：七折后处理结果（2026-10-30）

这是对已保存预测的后处理分析，不重新训练、不改模型。目标 ADT 只在评估时读取；平滑本身不使用任何蛋白值。

## 定义

对每个目标切片、每个蛋白独立做空间 kNN 平滑：

```text
p'_i = (1 - lambda) * p_i + lambda * mean_{j in kNN8(i)} p_j
```

- k=8，使用原始空间坐标（与模型 regional 邻居数相同）。
- lambda 为全局标量，候选 {0, 0.1, 0.2, 0.3, 0.4}。
- 正式读法：对每个留出折，lambda 由其余六折的平均 PCC-Pro 选出，再应用到该折；目标 ADT 不参与选 lambda。

## 解释与边界

- 蛋白丰度场本身有空间自相关；模型输出仍含 spot 级独立噪声，kNN 平均能稳定地降低误差类指标。
- PCC-Pro 的增益集中在 A1_LN/D1_LN，其他折接近持平或略降，因此不能宣称“所有折的相关性都提升”。
- 这是后处理，不是新结构；lambda 由七折交叉选择，不是外部独立验证。正式论文中应与未平滑结果并列报告，不能只报平滑后的数字。
- 未测 seed 方差；+0.004 的 PCC-Pro 均值提升可能处于单 seed 噪声边缘，但 RMSE 七折一致改善更可信。

## 决策

保留为推理期后处理候选，不替换五模型正式汇总，不改写已有结果表。若采用，需要在所有模型上同时报告 `lambda=0` 与 `lambda=0.3`（或六折选点）两列。
