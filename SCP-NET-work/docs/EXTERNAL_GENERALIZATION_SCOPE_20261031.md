# 外部泛化测试数据范围（历史记录）

> 本文件记录的是旧的 9764 基因映射方案。2026-11-01 起，10 个数据集正式实验改用 9384 个数据集共同 RNA 面板；本文件不再作为新的正式实验协议。

## 固定用途

以下三个数据集只作为泛化性外部测试集，不作为训练集、验证集或模型选择数据：

- `PBC_PR_6837`：新的乳腺癌病人
- `PBC_PR_6835_5A`：新的乳腺癌病人
- `GBM`：胶质母细胞瘤脑组织

## 禁止事项

- 不加入当前七切片训练注册表；
- 不参与模型参数更新；
- 不参与 checkpoint 或 epoch 选择；
- 不参与超参数、残差注入系数或图扩散强度选择；
- 不根据其 ADT 结果反向修改模型或预处理；
- 不把外部测试结果并入原七折主结果均值。

## 允许操作

- 使用与主项目一致的 RNA/ADT 预处理；
- 使用冻结模型进行 zero-shot 或预先定义的外部推理；
- ADT 只能用于最终外部测试指标，不能参与预测、checkpoint 或参数选择；
- 单独报告两个新乳腺癌病人和 GBM 的结果，并同时报告 RNA-only 基线。
