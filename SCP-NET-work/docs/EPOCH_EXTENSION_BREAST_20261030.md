# ProteinConvex延长训练实验

日期：2026-10-30。实验目的：确认20个epoch是否过短。

## 固定条件

基于ProteinConvex原始Breast_Cancer单折，唯一改变是`epochs: 20 -> 50`。
seed=42、训练/验证拆分、6源1目标、batch64、学习率、损失权重、
RNA特征50% dropout、邻居25% mask、数据和source-validation选点规则均保持不变。
没有增加数据、改变模型结构或读取目标ADT参与checkpoint选择。

## 结果

| 指标 | 20 epoch基线 | 50 epoch候选 | 候选减基线 |
|---|---:|---:|---:|
| 源验证最佳PCC-Pro | 0.751729（epoch20） | 0.757716（epoch47） | +0.005987 |
| Breast PCC-Pro | 0.602035 | 0.588353 | -0.013682 |
| Breast PCC-Spot | 0.633267 | 0.602464 | -0.030803 |
| Breast RMSE-Global | 0.299574 | 0.304314 | +0.004739 |
| Breast MAE-Global | 0.202944 | 0.206619 | +0.003675 |

50轮全部完成，最佳checkpoint由源验证集选为第47轮；保存预测为4160×31，
目标指标来自该checkpoint。源验证提升没有迁移到外层留出的Breast测试切片，
三项主要指标均退化。

## 决策

**拒绝50 epoch候选，ProteinConvex 20 epoch结果继续作为当前Breast工作基线。**
不把50轮结果写入正式五模型汇总，不扩展该候选的其他六个目标折。

这次结果说明延长训练不是当前问题的直接解决方案。源验证继续升高而目标切片下降，
更符合跨切片泛化和checkpoint代理指标不一致，而不是简单的训练轮数不足。
这是一折、单seed的受控负结果，不能证明所有更长训练预算都无效。

## 为什么验证集升高而目标测试下降

现有证据支持以下解释：

1. 源验证集是6个源切片内部各取10%的spot。它与训练spot共享源切片的表达分布和空间条件；Breast是完整未见过的外层目标切片。因此源验证PCC-Pro不是外部切片迁移能力的完美代理。
2. 训练损失从epoch20的0.057904继续降到epoch50的0.054635，说明模型仍在拟合源训练数据。源验证最高出现在epoch47，但这不能排除对源域特征的过拟合或跨切片泛化退化。
3. checkpoint只按源验证平均PCC-Pro选择。epoch47的源验证RMSE-Pro为0.190228，而epoch32为0.187858，说明相关性指标提高时误差尺度并未同步改善。目标测试的PCC和RMSE随后同时变差，符合选点代理不完全匹配的现象。
4. 31个蛋白中只有14个PCC提高、17个降低，退化不是单个指标四舍五入造成的，而是多个蛋白共同变化；SDC1、BCL2、FCGR3A的PCC下降尤其明显。

这些证据可以确认“延长训练没有改善外部切片泛化”，但不能仅凭这一折证明某个唯一机制。要进一步区分域偏移和选点指标问题，需要预先定义新的源切片级验证或多指标选点，并在不读取目标ADT的前提下重新做完整七折，不能用当前Breast测试结果反向挑epoch。
